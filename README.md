<h1>Using Wireshark and NetWitness Investigator to Analyze Wireless Traffic</h1>

<h2>Description</h2>
Using Wireshark, we can identify in-depth details about packages and frames, including 
source/destination ports, MAC address, IP addresses, as well as queries made when accessing websites 
where authentication is needed. Using NetWitness allows us to find the same information without 
having to look through what the lab calls “low-level wireless information.” It serves as a convenient tool, 
especially if you’re just looking for DNS related information. NetWitness has categories that help the user 
differentiate the specifications of the overall packet as a whole, as opposed to each individual frame. 
However, with an increase in development and a more sophisticated response to questions investigators 
might have, NetWitness comes with a price. It requires a license to be purchased and is not common 
across all spectrums of Network analysis. The majority of people can use Wireshark with little training 
and still accomplish the tasks necessary at the introductory levels of an investigation, though complex 
issues later on, such as the location of the transmitter, can be found with NetWitness. In this lab, we got 
our first glimpse at what NetWitness looks like, introducing its categories, learning how to upload files 
from the computer and start a new collection. Upon the completion of this lab, I would argue that 
NetWitness displays the data in a more user-friendly format and is overall a better and more useful tool 
than Wireshark. Though Wireshark is free to use and therefore easier to train with, I would recommend 
spending more time learning the ins and outs of NetWitness.
